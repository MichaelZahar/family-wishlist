# Family Wishlist — матрица прав

Статус: черновик · 2026-11-14. Основа: `prd.md` (R-…), `domain-model.md` (D-…). Реализация: модуль `authz` (ADR-003); каждая ячейка = тест.

## 1. Субъекты

| Субъект | Кто |
| --- | --- |
| **Владелец** | Профиль-владелец ресурса |
| **Управляющий** | Взрослый, управляющий детским профилем; действует от имени ребёнка |
| **Получатель** | Пользователь семьи, которому открыт вишлист (WishlistShare) |
| **Член семьи** | Пользователь той же семьи без доступа к ресурсу |
| **admin** | Роль в семье; дополнительно к своей роли по ресурсу |
| **Гость** | Без аккаунта, по активной ShareLink |
| **Чужой** | Пользователь другой семьи — запрещено всё (D-01) |

Обозначения: ✅ — можно; ❌ — нельзя.

## 3. Решения

- ✅ Гостевую бронь отменяет только admin: владелец вишлиста о бронях не знает (R-RES-01).
- ✅ Q-12 → А: admin видит только вишлисты, открытые ему; R-RES-03 действует в них.
- ✅ Q-13 → А: получатель видит «занято» без имени дарящего (R-RES-08).
- ✅ Q-14 → Б: управляющий — дарящий: видит брони и дарящих в вишлистах ребёнка и может бронировать (R-RES-09).
